## Why not the others

- **Gitea** is close, but the governance split makes Forgejo the safer long-term bet.
- **Sourcehut** is lovely and minimal; the email-based review flow is a hard sell for the team.
- *GitHub* stays as a public mirror only.

> Pick boring infrastructure, then make it pleasant.

Run a quick check with `forgejo doctor check --all`, or see the [Forgejo docs](https://forgejo.org/docs/latest/).

```bash
docker compose up -d forgejo runner
```
